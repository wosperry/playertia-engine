# Engine

`engine/` 只保存可以被多个场景复用的生产代码。

- `physics/`：当前已实现的三指针物理核心。
- `runtime/`：未来共享场景时钟、生命周期、输入快照和输出事件的边界。

代码进入公共引擎前，应至少满足一项：

1. 已被两个真实场景使用；
2. 属于所有场景必须共享的确定性基础设施；
3. 独立测试能够证明抽象没有改变已有场景行为。

场景规则、视觉资源、关卡和产品交互不得为了“看起来通用”而提前塞进公共引擎。

`engine/` 内的 C++ 类型允许随物理模型演进；对应用开发者提供的兼容边界位于
`sdk/c/`。平台包不得把内部类、私有状态或 C++ ABI 当作公开契约。

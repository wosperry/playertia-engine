# 物理指针手表

当前第一优先级场景。

目标不是制造万能智能手表，而是完成一个只负责准确看时间和物理解压的腕上装置：

- 正常状态准确显示时间；
- 按键释放后，三根指针进入真实物理运动；
- 倾斜、甩动、表盘自转和触摸都会改变轨迹；
- 每根指针具有独立质量分布、惯量、阻尼和柔性；
- 无操作后平滑回归未来时刻的正确位置。

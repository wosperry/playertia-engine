# ESP32-S3 物理指针手表核心交互与数学模型

## 1. 文档目的

本文定义基于 ESP32-S3-Touch-AMOLED-1.8、触摸屏和 QMI8658 六轴 IMU 的
“物理指针手表”核心交互。目标不是只播放预制动画，而是让时针、分针、秒针作为
具有质量、惯性、阻尼和可选柔性的独立物体，真实响应设备姿态、设备运动和用户触摸，
并在停止操作后回到当前正确时间。

本文重点回答：

1. 按键如何解除时间约束并切换到重力交互；
2. 加速度计和陀螺仪分别负责什么；
3. 每根指针如何拥有独立基准和独立物性；
4. 触摸、按键、IMU 与自动回归如何仲裁；
5. 自然摆动和舒适曲线回归如何实现；
6. 无操作定时器如何定义，避免被传感器噪声不断重置；
7. 材质、阻尼、柔性弯曲和自动脱手如何参数化；
8. 世界惯性系、移动铰点和表盘最小坐标如何严格等价；
9. 数值仿真如何保持稳定、连续且可调试。

## 2. 需求摘要

### 2.1 核心体验

正常状态下，三根指针准确显示当前时间。用户短按指定实体按键后，系统解除“时间位置”
对指针的锁定，切换到重力交互状态：

- 设备竖直正放时，屏幕内重力方向接近六点方向；
- 设备倾斜或旋转时，重力方向和设备惯性随之变化；
- 三根指针按照各自质量分布、长度、质心、转轴阻尼和柔性独立运动；
- 用户触摸并拨动某根指针时，触摸控制优先于 IMU；
- 用户停止操作一段可配置时间后，指针回到各自正确时间位置；
- 回归方式可以由用户选择“自然摆动”“舒适曲线”或“混合回归”。

这里的“按键松开时间”定义为：

> 按键触发后，松开指针与正确时间位置之间的锁定约束，而不是把时间停止。

RTC 仍然持续走时，正确时间基准也始终在后台连续更新。

### 2.2 第一版范围

第一版建议包含：

- 实体按键进入重力交互；
- 加速度计与陀螺仪融合；
- 三根刚性指针独立仿真；
- 触摸捕获、拖动和甩出；
- 无操作定时回归；
- 自然摆动、舒适曲线和混合回归三种策略；
- 每根指针独立材质参数；
- 固定时间步仿真和基本异常保护。

柔性弯曲、多段指针、碰撞音效和复杂指针碰撞可以在第一版稳定后逐步加入，但数据结构
应提前预留。

## 3. 需要特别注意的 26 类问题

1. **按键语义**：按下还是松开时切换模式，必须唯一确定并消抖；
2. **全局模式与单针状态分离**：手表模式是全局的，触摸捕获状态属于单根指针；
3. **传感器职责不能混淆**：加速度计测比力，陀螺仪测角速度；
4. **传感器融合**：不能仅靠陀螺仪长期计算重力方向，否则必然漂移；
5. **坐标系映射**：IMU 轴、PCB 方向、屏幕旋转方向必须标定；
6. **屏幕平放退化**：重力在屏幕平面的投影接近零时，方向没有可靠意义；
7. **每根指针独立基准**：三根指针需要独立目标角、速度、物性和状态；
8. **公共重力与独立基准的区别**：真实有效场公共，质心几何偏置、艺术基准偏置和独立
   响应必须分开；
9. **角度周期性**：必须正确处理 `0°/360°` 和多圈旋转；
10. **触摸优先级**：被触摸指针不能同时与 IMU 或自动回归“抢控制权”；
11. **松手连续性**：释放时必须保留触摸速度和柔性储能，不能发生速度跳变；
12. **回归策略差异**：自然摆动是动力学过程，舒适曲线是受控轨迹，不能混成同一参数；
13. **无操作定义**：传感器噪声和指针自主摆动不能被算作用户操作；
14. **材质参数边界**：过硬、过轻或低阻尼参数可能导致数值爆炸或永不收敛；
15. **柔性指针稳定性**：弯曲关节越多，固定时间步和约束求解越重要；
16. **正确时间持续移动**：回归目标不是一个静止角，而是随 RTC 连续前进；
17. **休眠与校时跳变**：唤醒、NTP 校时、时区变化需要单独处理；
18. **可测试与可观测性**：必须能够显示原始 IMU、融合姿态、各项扭矩和当前状态；
19. **中心支点激励**：手腕甩动首先规定表盘中心的运动，不是直接给三根指针同一角速度；
20. **IMU 安装偏心**：传感器测到的是其芯片位置的比力，不一定等于表盘中心的比力；
21. **材质与几何不可混淆**：密度、质量分布、转动惯量、柔性和轴承阻尼需要分别建模；
22. **连续力与冲量不可重复**：甩动既可逐采样积分，也可短时近似为冲量，但不能叠加两次；
23. **二维与三维模型边界**：只绕屏幕法向旋转时可用二维简化式，任意三维转腕需要额外
    检查离心广义力矩；
24. **量程饱和不可恢复**：加速度计或陀螺仪削顶后，真实峰值和冲量无法由软件唯一还原，
    只能标记不可信并限制注入能量；
25. **绝对位置不可观测且非必需**：六轴 IMU 双积分位置会快速漂移，指针动力学只需要
    表心有效加速度；
26. **世界惯性不等于自由陀螺**：机械表针仍受移动铰点和旋转表盘平面约束，三维倾斜时
    不能无条件冻结世界方向。

## 4. 术语与基准定义

### 4.1 三类基准

每根指针 `i` 同时可以拥有三类基准，但同一时刻只有一种拥有主要控制权。

#### 时间基准 `TIME_REF_i(t)`

该指针在当前真实时间下应该显示的正确角度。时针、分针、秒针的时间基准互不相同，
并且随 RTC 连续移动。

#### 重力基准 `GRAVITY_REF_i(t)`

严格物理模式中，三根指针共享同一个表心有效加速度场，实际力矩直接由向量计算，不需要
人为给每根指针创造不同重力方向。为状态机和界面显示，可把其稳定方向记为：

```text
GRAVITY_REF_i = 表心有效加速度的屏内稳定方向
```

真实世界只有一个重力方向。所谓“每根指针有自己的重力基准”，在物理一致的实现中
应解释为：

- 三根指针分别保存自己的基准实例；
- 每根指针具有不同质量分布、质心、转动惯量、转轴阻尼和柔性；
- 即使重力方向相同，三根指针的运动轨迹也不同。

真实的质心几何偏置 `δ_com,i` 应写入该指针的质心向量。若产品希望获得艺术化的独立
稳定方向，可额外定义：

```text
GRAVITY_REF_stylized,i =
    公共稳定方向 + β_ref,i
```

默认 `β_ref,i = 0`，并在配置中明确它是风格化参数，不是现实中存在三套重力。

#### 触摸基准 `TOUCH_REF_i(t)`

用户捕获某根指针后，由触摸点相对表盘中心的位置实时生成。触摸基准只作用于被捕获
的指针，并具有最高交互优先级。

### 4.2 建议坐标系

定义三个坐标系：

- `W`：世界惯性坐标系；
- `B`：表盘/机身坐标系，原点位于表盘中心；
- `M`：IMU 芯片原始坐标系。

物理引擎统一使用 `B` 系：

- 原点：表盘中心；
- `x` 轴：向右为正；
- `y` 轴：向下为正；
- `z` 轴：指向屏幕内部，从而使 `x × y = z` 构成右手系；
- 指针角度 `θ`：从十二点方向开始，顺时针为正；
- 十二点为 `0`；
- 三点为 `π/2`；
- 六点为 `π`；
- 九点为 `3π/2`。

角度为 `θ` 的单位方向向量：

```text
u(θ) = (sin θ, -cos θ)
```

对应的正角度切向单位向量为：

```text
t(θ) = ∂u/∂θ = (cos θ, sin θ)
```

此定义与钟表视觉方向一致，同时仍保持三维叉乘的右手规则。IMU 原始轴必须通过固定
旋转矩阵 `C_BM` 从 `M` 系转换到 `B` 系；不得假设芯片丝印方向、PCB 方向和屏幕方向
天然一致。

## 5. 全局模式与单指针状态机

### 5.1 全局模式

```text
TIME_DISPLAY
    │
    │ 实体键短按：解除时间约束
    ▼
GRAVITY_PLAY
    │
    │ 达到无操作超时
    ▼
AUTO_RETURN
    │
    │ 三根指针均完成归位
    ▼
TIME_DISPLAY
```

可选的系统级状态：

- `SLEEP`：屏幕关闭、暂停物理仿真；
- `CALIBRATING`：传感器偏置和坐标方向校准；
- `ERROR_FALLBACK`：IMU 异常时退化为普通表盘。

### 5.2 每根指针独立状态

```text
TIME_LOCKED
    │
    │ 进入重力交互
    ▼
IMU_FREE
    │
    │ 触摸命中该指针
    ▼
TOUCH_CAPTURED
    │
    │ 手指松开或超过材质脱手阈值
    ▼
TOUCH_RELEASED
    │
    │ 释放过渡结束
    ▼
IMU_FREE

IMU_FREE / TOUCH_RELEASED
    │
    │ 全局进入自动回归
    ▼
RETURNING
    │
    │ 满足位置和速度阈值
    ▼
TIME_LOCKED
```

全局模式和单针状态必须分开。例如用户只抓住分针时：

- 分针处于 `TOUCH_CAPTURED`；
- 时针和秒针仍处于 `IMU_FREE`；
- 全局仍然处于 `GRAVITY_PLAY`。

## 6. 输入优先级与仲裁

建议优先级如下：

```text
系统安全事件 / 休眠
        >
触摸捕获
        >
材质脱手条件
        >
实体按键模式切换
        >
自动回归控制
        >
IMU 外力
        >
时间弱吸附与普通阻尼
```

具体规则：

1. 被触摸指针以触摸约束为主；
2. 第一版中，被捕获指针的 IMU 权重建议设为零；
3. 未被触摸的指针继续响应 IMU；
4. 触摸发生在 `AUTO_RETURN` 时，立即取消该指针的回归并进入触摸捕获；
5. 实体按键在触摸过程中触发时，建议记录模式切换请求，并在触摸结束后执行；
6. 自动回归永远不能强行抢走正在触摸的指针；
7. 低电量、关机等系统事件仍然拥有最高优先级。

加入柔性指针后，可以只让“触点”严格服从手指，而让触点之外的指针段继续受到重力、
惯性和弹性影响。达到材质脱手条件时，系统才有权解除触摸捕获；在此之前，IMU 不能
直接使触点脱离手指。

触摸不是直接覆盖指针角度，而是建立高刚度物理约束：

```text
τ_touch =
    clamp(
        Kp × 最短角度差(θ_touch, θ_hand)
      + Kd × (ω_touch - ω_hand),
        -τ_grip,max,
        +τ_grip,max
    )
```

这样拖动时仍然存在重量、滞后和弹性，而不是普通 UI 元素的刚性跟手。

`τ_grip,max` 是手指与当前材质/触点之间的最大虚拟保持力矩。若不设置上限，触摸弹簧
可以凭空施加无限大力矩，材质弯曲阈值和自动脱手条件就失去物理意义。

## 7. IMU 的正确用法

### 7.1 加速度计和陀螺仪的职责

必须明确：

- **加速度计**输出的是包含重力与设备线性运动影响的比力；
- **陀螺仪**输出设备绕三个轴的角速度；
- **陀螺仪不能直接测得重力加速度**；
- 陀螺仪角速度积分可得到短时间姿态变化，但长期会因零偏而漂移；
- 重力方向主要由加速度计提供长期参考，陀螺仪提供短时快速响应；
- 设备的角加速度可由陀螺仪角速度对时间求导后估计，但必须滤波。

因此，“根据陀螺仪计算更符合物理规律的加速度”应落实为：

1. 加速度计测量重力与中心运动合成后的比力；姿态链只在低动态时把它作为长期重力参考；
2. 陀螺仪估计旋转角速度；
3. 若需要 IMU 偏心修正，对带限后的陀螺仪角速度求导以估计设备角加速度；
4. 通过互补滤波、Madgwick 或 Mahony 等方法融合姿态；
5. 动力学链将校准并完成偏心修正的负比力直接作为表心有效场，不从姿态融合结果重复
   构造另一份重力。

### 7.2 姿态融合

简单原型可使用互补滤波：

```text
姿态融合值 =
    α × (上一姿态 + 陀螺仪角速度 × dt)
  + (1 - α) × 加速度计姿态
```

其中 `α` 接近 1。实际值必须根据采样率和滤波截止频率计算或实测调节，不能将某个
固定经验值直接用于所有采样率。

正式实现推荐使用四元数姿态：

```text
q_pred(t + dt) =
    normalize(
        q(t)
        ⊗ Exp_q(0.5 Ω^B dt)
    )

q(t + dt) =
    normalize(
        q_pred
        ⊗ q_accel_correction
    )
```

这里以 `q = q_WB`、右乘机身角速度增量为例；若库使用相反旋转方向或左乘约定，顺序
必须整体一致。`q_accel_correction` 是门控后的微小姿态修正，不是把一个加速度向量直接
加到四元数上。使用四元数可以避免欧拉角接近特定姿态时的奇异问题。

本设备没有磁力计，因此绝对航向角不可观测并会缓慢漂移。但本项目主要需要重力在
屏幕平面的投影以及短时旋转变化，对绝对指南针方向没有依赖。

快速甩动时，加速度计模长会明显偏离静止时的 `1g`，此时不应强行用它校正重力方向。
建议根据模长偏差动态降低加速度计在姿态融合中的权重，短时间更多相信陀螺仪预测；
运动减弱后再平滑恢复加速度计校正。

### 7.3 屏幕内重力方向

将融合得到的重力向量转换到屏幕坐标，得到：

```text
g_screen = (g_x, g_y, g_z)
g_parallel = (g_x, g_y)
G_parallel = sqrt(g_x² + g_y²)
```

在本文角度约定下，屏幕内重力方向为：

```text
φ_g = atan2(g_x, -g_y)
```

设备竖直正放时，`g_y > 0`，所以 `φ_g` 接近 `π`，也就是六点方向。

### 7.4 屏幕平放时的退化

当屏幕正面朝上或朝下时，重力主要落在屏幕法向轴：

```text
G_parallel ≈ 0
```

此时用 `atan2(g_x, -g_y)` 得到的方向会被微小噪声支配，表现为指针随机乱跳。

必须设置退化策略：

- 当 `G_parallel` 低于阈值时冻结最后一个可靠方向；
- 或逐渐衰减重力扭矩，只保留转动惯性；
- 或平滑回到用户配置的默认方向；
- 进入和退出退化区必须使用不同阈值，形成迟滞，避免频繁切换。

这个退化只针对“从姿态得到的静态重力方向”。设备平放时若用户沿屏幕平面加速，
`a_eff,O^B` 的平面分量仍然是有效的真实基座激励，不能因为 `G_parallel` 很小而一并
删除。严格物理路径直接对 `a_eff,O^B` 做切向点积：静止平放时力矩自然趋零，平移甩动
时则保留动态响应。

### 7.5 设备旋转和甩动

陀螺仪给出屏幕法向角速度 `ω_device,z`。设备角加速度近似为：

```text
α_device,z =
    low_pass((ω_device,z[k] - ω_device,z[k-1]) / dt)
```

对绕中心转动的刚性指针，可以加入参考系惯性扭矩：

```text
τ_rotation,i = -I_i × α_device,z
```

这是“角加速度显式形式”。正式刚性实现更推荐第 9.1 节的共轭角动量形式，直接用
`Ω_z` 更新相对角速度，从而避免主方程对陀螺仪做差分。两种形式数学等价，只能选择
一种。

原始差分会明显放大噪声，因此需要：

- 陀螺仪零偏校准；
- 时间戳使用真实 `dt`；
- 低通滤波；
- 死区；
- 最大角加速度限制；
- 异常样本剔除。

旋转参考系中一个普通质点的相对加速度关系包含平移、欧拉、离心和科里奥利项：

```text
a_effective =
    g
  - a_origin
  - α × r
  - ω × (ω × r)
  - 2ω × v_relative
```

但不能把这四项不加分析地全部转换成指针角扭矩。对绕同一中心、定长、仅允许面内
旋转的单刚体指针：

- 若表壳主要绕屏幕法向旋转，离心项和科里奥利项对中心的广义扭矩为零；
- 若表壳存在明显的任意三维角速度，离心项一般不再是纯指针径向，可能产生面内广义
  力矩；
- 在理想的单自由度细长刚性指针模型中，科里奥利项沿指针的广义切向投影仍为零；
- 表壳角加速度只有屏幕法向分量直接产生面内欧拉惯性力矩。

因此，二维近似下的核心角向作用是：

1. 屏幕内重力投影；
2. 表盘中心平移形成的等效惯性场；
3. 绕屏幕法向的角加速度欧拉惯性。

任意三维刚体模型还需要第 9.1 节给出的离心广义力矩。柔性多段指针存在多个自由度，
离心和科里奥利效应还会影响内部关节力，此时应由完整多体动力学方程统一产生，而不是
手工给每一段附加经验角扭矩。

需要特别避免重复计算同一个外力。例如已经把加速度计原始比力作为指针有效外力时，
不能再无条件叠加一个完整的 `1g` 重力向量。实际驱动输出的符号和轴方向也可能不同，
必须通过静止六面标定确认后再采用公式。

### 7.6 缓慢旋转手表时的连续重力响应

进入 `GRAVITY_PLAY` 后，重力方向不能只在释放瞬间计算一次。它是一个随设备姿态持续
变化的平衡方向：

```text
释放指针
    ↓
三根指针在重力作用下趋向当前重力方向
    ↓
用户缓慢旋转手表本体
    ↓
重力在屏幕坐标中的方向连续移动
    ↓
指针受实时重力扭矩、惯性和阻尼作用
    ↓
以不同的滞后和摆动轨迹追向新的重力方向
```

令手表外壳相对世界的屏幕面内旋转角为 `ψ_device(t)`，世界重力方向保持不变，则在
屏幕坐标中可近似理解为：

```text
φ_g(t) = wrap(φ_world - ψ_device(t))
φ̇_g(t) ≈ -ψ̇_device(t)
```

这组关系用于解释行为，不能只靠陀螺仪积分长期生成重力方向。实现上应分清：

- 姿态/界面路径可从融合后的重力向量计算 `φ_g`；
- 严格物理路径直接使用经表心修正的 `a_eff,O^B = -f_O^B`；
- 两条路径不能把同一份重力再次相加。

在屏幕坐标中，若表壳主要绕屏幕法向旋转，单根刚性指针的二维简化方程为：

```text
I_i θ̈_i =
    m_i l_c,i A_eff sin(φ_eff(t) - θ_i)
  - c_i θ̇_i
  - d_i |θ̇_i|θ̇_i
  - I_i α_device,z
```

这里：

- `φ_eff(t)` 是重力与表盘中心平移惯性合成后的持续移动平衡方向；
- 缓慢、近似无平移旋转时，`φ_eff(t) ≈ φ_g(t)`；
- 第一项让指针向当前有效重力方向回归；
- `c_i` 和 `d_i` 体现转轴摩擦与高速介质阻力；刚体整体旋转的耗散不能直接归因于
  材料内部阻尼；
- `-I_i α_device,z` 体现手表本体角加速时指针相对外壳的惯性滞后；
- 方程必须逐物理步积分，不能直接执行 `θ_i = φ_g`。

当用户以近似恒定的低速旋转手表时，`α_device,z` 很小，主要表现为移动重力方向与阻尼
共同作用。理想视觉结果是：

- 指针大体保持朝向世界重力方向；
- 在屏幕里看，指针随外壳旋转而相对转动；
- 指针相对新重力方向存在材质相关的相位滞后；
- 低阻尼指针更容易摆动，停止旋转后可能越过目标；
- 高阻尼指针更容易被外壳拖拽，跟随更平稳但可能产生更明显的稳态滞后；
- 转动惯量主要影响开始旋转和停止旋转时的瞬态响应；
- 用户停止旋转后，三根指针分别围绕新的重力方向衰减摆动并收敛。

三根指针已经全部朝向重力方向时仍不能合并为一根共享状态。它们可以暂时视觉重叠，
但仍要分别积分各自角度、角速度、惯量、阻尼和柔性状态。这样旋转开始后，它们才会
自然分离并表现出不同材质特征。

实现时还要注意：

- 对重力向量 `g_x/g_y` 滤波后再计算角度，不要直接对包裹后的 `φ_g` 做普通平均；
- 若需要计算 `φ̇_g`，必须先做角度解包裹；
- 缓慢旋转不应被死区完全吃掉；
- 快速旋转时再加入经滤波的角加速度惯性；
- 屏幕逐渐转为平放时，应随 `G_parallel` 衰减姿态链的静态重力扭矩，但保留动力学链
  测得的平面甩动分量；
- 设备本体旋转带来的触摸坐标变化不能误判为手指拖动。

### 7.7 当前甩动模型审计

此前模型中以下部分是正确的：

- 每根指针必须独立保存角度、角速度、惯量和阻尼；
- 重力方向是连续变化的平衡方向；
- 表壳角加速度会使指针产生相对外壳的惯性滞后；
- 物理仿真必须逐固定时间步积分，不能直接修改指针角度。

但“手腕甩动”部分仍有四个不严谨之处，需要修正：

1. `τ_linear_accel` 只被列为一个附加扭矩，没有定义它来自表盘中心的哪一个加速度；
2. 将“重力”和“加速度计测得的加速度”直接相加，可能把重力计算两次；
3. 加速度计位于 PCB 上的实际安装点，它在旋转时的读数不一定等于表盘中心读数；
4. 过去把离心、科里奥利项笼统删除，只对“表壳主要绕屏幕法向旋转”的二维近似成立；
   任意三维转腕时必须按广义坐标逐项投影。

正确模型属于“移动支点、旋转基座上的复摆”，也称基座激励物理摆。

手腕或外力首先使表壳运动。表壳通过中心转轴约束指针根部跟随表盘中心 `O` 平移。
因此，不能把“甩动力”理解成在表盘中心直接给所有指针施加相同角速度。更准确的解释是：

> 表盘中心具有规定的平移加速度和角加速度；在表壳参考系中，每根指针的全部质量受到
> 等效惯性场。该惯性场的合力等效作用于各自质心，再绕中心转轴产生扭矩。

三根指针共享同一个表盘中心加速度，但由于质心位置、转动惯量、阻尼和柔性不同，
得到的角运动不相同。

### 7.8 表盘中心的有效加速度

定义：

- `W`：近似惯性世界坐标系；
- `B`：固定在表盘上的机身/屏幕坐标系；
- `O`：表盘中心和三根指针的共同转轴；
- `A_O^W`：表盘中心在世界系中的平移加速度；
- `g^W`：世界系中的重力加速度；
- `R_BW`：将世界系向量转换到表盘系的旋转矩阵。

表盘系中对所有指针共同生效的“有效重力/惯性加速度场”为：

```text
a_eff,O^B = R_BW × (g^W - A_O^W)
```

它已经把真实重力和中心平移惯性合并为一个量：

- 设备静止时，`A_O^W = 0`，所以 `a_eff,O^B` 就是屏幕坐标中的重力；
- 设备向右加速时，指针在表盘系中额外感到向左的惯性；
- 自由落体时，`A_O^W ≈ g^W`，所以 `a_eff,O^B ≈ 0`；
- 任意甩动时，指针响应的是 `g^W - A_O^W`，不是简单的 `g + A_O`。

对每根指针，中心平移和重力产生的合成扭矩可以直接写为：

```text
τ_eff,i =
    [r_c,i^B(θ_i) × m_i a_eff,O^B]_z
```

也可以使用对广义坐标的虚功形式：

```text
τ_eff,i =
    m_i
    [∂r_c,i^B(θ_i) / ∂θ_i]ᵀ
    a_eff,O^B
```

两式完全等价。程序应优先使用这个向量形式，避免先计算一个噪声很大的方向角。

在本文的钟表角度约定下：

```text
r_c,i(θ_i) =
    l_c,i × (sin θ_i, -cos θ_i)
```

若：

```text
A_eff = sqrt(a_eff,x² + a_eff,y²)
φ_eff = atan2(a_eff,x, -a_eff,y)
```

则标量形式为：

```text
τ_eff,i =
    m_i l_c,i A_eff
    × sin(φ_eff - θ_i)
```

这条公式同时覆盖静态重力、缓慢倾斜和快速线性甩动。单独的
`τ_gravity + τ_linear_accel` 只是它的一种拆分写法；实现时更推荐直接计算
`a_eff,O^B`，避免符号错误和重力重复叠加。

若 `A_eff` 接近零，向量式会让力矩自然连续趋近零；此时不必依赖不稳定的 `atan2`
结果决定物理力矩。`φ_eff` 只适合调试显示和解释。

还应区分两种容易混用的偏置：

- `δ_com,i`：质心轴相对视觉指针轴的真实几何偏置，应写入 `r_c,i(θ_i)`；
- `β_ref,i`：产品希望加入的艺术化重力基准偏置，应作为虚拟场/控制器参数。

两者可能产生相似画面，但物理含义和符号不同，不能共用一个含糊的 `β_i`。

### 7.9 加速度计读数不是世界线性加速度

理想加速度计输出的是传感器安装点 `S` 的比力：

```text
f_S^B =
    R_BW × (A_S^W - g^W)
```

若驱动输出以 `g` 为单位，包含零偏、比例误差和 IMU 到表盘的安装旋转，建议显式写成：

```text
f_S^B =
    g0 × C_BM × M_a
    × (a_raw^M - b_a)

Ω^B =
    C_BM × M_g
    × (ω_raw^M - b_g)
```

其中：

- `C_BM`：从 IMU 芯片坐标 `M` 到表盘坐标 `B` 的固定旋转矩阵；
- `M_a`、`M_g`：比例和交叉轴校正矩阵；
- `b_a`、`b_g`：零偏；
- `g0`：标准重力换算，仅当加速度原始单位为 `g` 时使用；
- 陀螺仪进入物理引擎前统一换成 `rad/s`。

至少使用六面静态测试确认加速度轴、符号和比例，并用绕三轴的已知方向旋转确认陀螺仪
轴映射。仅凭开发板原理图或驱动变量名不足以保证坐标正确。

因此，如果传感器恰好位于表盘中心且已完成符号、零偏和比例校准：

```text
a_eff,O^B = -f_O^B
```

这意味着物理引擎的动态外力路径可以直接使用“校准后比力的相反数”，不需要先把重力
和线性加速度分离后再重新相加。姿态融合仍然有价值，但主要用于：

- 判断重力方向质量；
- 处理屏幕平放退化；
- 获取表壳角速度和角加速度；
- 提供调试与手势识别；
- 校正传感器安装方向。

#### 传感器不在表盘中心时

令 `r_OS^B` 为表盘中心 `O` 指向 IMU 安装点 `S` 的固定向量，表壳角速度和角加速度为
`Ω^B`、`α^B`。因为传感器固定在 PCB 上：

```text
A_S^W =
    A_O^W
  + α × r_OS
  + Ω × (Ω × r_OS)
```

转换到表盘系后，中心有效加速度为：

```text
a_eff,O^B =
    -f_S^B
  + α^B × r_OS^B
  + Ω^B × (Ω^B × r_OS^B)
```

其中：

- `α × r_OS` 是 IMU 安装点相对中心的切向加速度；
- `Ω × (Ω × r_OS)` 是安装点的向心加速度；
- 传感器固定在表壳上，因此该修正式没有相对运动的科里奥利项；
- `r_OS` 应由 PCB/CAD 尺寸或实测得到；
- 若第一版忽略 `r_OS`，必须明确这是“小偏心、低转速”近似。

在快速转腕时不做偏心修正，会把 IMU 因离开中心而测到的切向/向心加速度误认为整个
表盘中心的平移甩动，从而给三根指针注入错误扭矩。

修正量的保守上界为：

```text
|Δa_center| <= |α| |r_OS| + |Ω|² |r_OS|
```

因此是否可以忽略偏心，应根据实际安装距离和动作录制中的角速度、角加速度估算，而不
应只凭肉眼判断 PCB 很小。

`α` 不能由原始陀螺仪做单点差分。可使用带限微分器、局部多项式导数或小型状态
观测器；加速度和陀螺仪路径必须匹配时间戳与群延迟，否则
`α × r_OS` 会与本应抵消的加速度样本错位，制造虚假冲击。

### 7.10 动态路径与姿态路径应分开

推荐并行维护两条传感器处理路径：

#### 动力学路径

```text
原始加速度计
    ↓ 零偏、比例和轴映射校准
比力 f_S^B
    ↓ IMU 偏心修正
中心有效加速度 a_eff,O^B
    ↓ 带宽限制、异常检测、限幅
逐物理步计算三根指针扭矩
```

这条路径应保留用户甩动的动态成分，不能用过强低通把动作消掉。

#### 姿态路径

```text
加速度计 + 陀螺仪
    ↓ 互补/Mahony/Madgwick 等融合
姿态、重力方向、角速度
    ↓
慢速重力稳定、平放退化、手势和质量判断
```

快速甩动时，加速度计不再是纯重力参考，姿态融合应降低它的校正权重；但动力学路径
仍可使用它测到的比力作为真实基座激励输入。

### 7.11 连续力与短时冲量

正式仿真建议每个物理步使用 `a_eff,O^B(t)` 连续积分。对于持续时间远小于指针固有
周期的短促甩动，可使用角冲量作分析和单元测试：

```text
J_eff = ∫ a_eff,O^B(t) dt
```

在冲击期间指针角度近似不变、且采用二维法向旋转近似时：

```text
I_i Δω_i ≈
    [r_c,i × m_i J_eff]_z
  - I_i ΔΩ_z
```

因此：

```text
Δω_i ≈
    (m_i / I_i)
    [r_c,i × J_eff]_z
  - ΔΩ_z
```

任意三维细杆模型还要积分离心广义力矩：

```text
Δω_i ≈
    (H_i / I_i) t_iᵀ J_eff
  - ΔΩ_z
  - ∫(Ω · u_i)(Ω · t_i) dt
```

这条关系可用于验证“向某个方向短促甩动后，三根指针初始角速度是否合理”。

连续积分和冲量近似是同一个物理过程的两种表示。程序若已经逐样本积分加速度，不能在
检测到“甩动事件”后再次额外施加同一冲量，否则会把能量计算两遍。

加加速度 `jerk = da/dt` 可用于甩动事件检测、插值或滤波，但它不是新的基本力项，
不能再乘一个经验系数作为额外扭矩叠加。

### 7.12 QMI8658 采样与量程要求

QMI8658 支持可编程加速度计、陀螺仪量程和输出数据率。官方资料给出的最大范围包括
加速度计 `±16g`、陀螺仪 `±2048°/s`，并带有可编程滤波与 FIFO：

- [QMI8658 官方产品说明](https://www.qstcorp.com/en_imu_prod/QMI8658)
- [QMI8658 数据手册](https://files.waveshare.com/wiki/common/QMI8658A.pdf)

甩动模式需要注意：

- `±2g` 适合缓慢姿态但很容易在故意甩动时饱和；
- 应先记录真实动作峰值，再选择保留余量的量程；
- 量程过大则降低小动作分辨率，需要在动态范围与噪声之间折中；
- 加速度计或陀螺仪达到满量程时必须记录饱和标志；
- 饱和样本不能被当作准确峰值继续积分，否则轨迹和冲量都会被低估；
- 使用 FIFO 或硬件时间节奏获得稳定采样间隔；
- 将 IMU 样本按时间戳插值/保持到固定物理时间步；
- 角加速度不能用未滤波的相邻陀螺仪样本直接相减；
- 建议使用带限微分器、低通微分或小型状态观测器估计 `α`；
- 所有传感器轴先通过固定矩阵转换到统一表盘坐标。

动力学路径需要保留有意义的甩动带宽，但仍应校正传感器零偏并抑制明显高频噪声。
这里的“零偏校正”不是对整条加速度做高通；真实静态重力和持续基座加速度都是物理
输入，不能作为直流分量被一并删除。滤波设计应用动作录制数据验证，不能只看静止曲线
调参。

### 7.13 为什么不需要、也不能只靠六轴 IMU 恢复绝对位置

以三维世界为物理基准是正确的，但“世界基准”不等于必须实时求出表盘中心的绝对坐标
`x_O^W(t)`。

六轴 IMU 直接观测的是：

- 传感器位置的比力 `f_S = A_S - g`；
- 表壳角速度 `Ω`。

它不直接观测绝对位置或绝对速度。将加速度连续积分一次会累积速度误差，积分两次会把
很小的零偏、姿态误差和噪声迅速放大为位置漂移；而且单个六轴 IMU 在一般运动中无法
唯一分离重力和线性加速度。

例如仅 `10 mg ≈ 0.098 m/s²` 的恒定加速度误差，在初始误差为零的理想积分中，`10 s`
后就会造成约：

```text
0.5 × 0.098 × 10² ≈ 4.9 m
```

的位置误差，远大于手表交互所允许的尺度。

本项目恰好不需要做这种不可控的双积分。指针相对移动铰点的动力学只依赖：

```text
a_eff,O^B = R_BW (g^W - A_O^W)
Ω^B
必要时的 α^B
```

其中 `g - A_O` 已由中心修正后的加速度计负比力直接给出。在本项目采用的均匀重力、
表壳内相对阻尼且不存在位置相关外场的模型中，绝对位置 `x_O` 和匀速平移速度都会在
约束动力学中消去；把整个手表平移到房间另一处不会改变指针相对表盘的轨迹。

因此建议：

- **概念和推导层**：以世界惯性系为真值，描述移动铰点和旋转表盘；
- **传感器和计算层**：使用表盘系中的 `-f_O`、`Ω` 和相对角状态；
- **调试层**：可用融合姿态把指针方向转换到世界系观察；
- **不要**仅靠六轴 IMU 双积分构造一个虚假的“世界绝对位置”。

坐标系本身只是记账方式，不决定模型是否“更物理”。从世界系推导、再消去约束得到的
表盘系方程与直接使用世界系约束求解器在数学上等价。前者更适合当前设备，因为 IMU
输出和屏幕渲染天然都在表盘系；世界系则更适合解释、证明和离线验证。

这里的世界系也只需是开机时建立的局部惯性系，其原点和水平朝向可以任意选择。本设备
没有磁力计，绝对航向不可长期观测，但整体绕世界竖直轴旋转这个“坐标规范自由度”不会
改变内部指针相对表盘的动力学。

只有接入相机、UWB、外部光学定位等额外位置参考后，才有必要维护长期可信的
`x_O^W(t)`；即使有这些数据，内部指针动力学通常仍只需要它的加速度而非绝对位置。

## 8. 每根指针的独立时间基准

令当前连续时间包含毫秒部分：

```text
s = 秒 + 毫秒 / 1000
m = 分 + s / 60
h = (小时 mod 12) + m / 60
```

三根指针的正确时间角度：

```text
θ_second,target = 2π × s / 60
θ_minute,target = 2π × m / 60
θ_hour,target   = 2π × h / 12
```

对应的连续目标角速度：

```text
ω_second,target = 2π / 60
ω_minute,target = 2π / 3600
ω_hour,target   = 2π / 43200
```

采用连续时间可以避免秒针每秒突然跳变，也使回归终点可预测。

内部物理状态建议保存“未包裹角度”，允许指针旋转多圈。只有绘制和计算最短目标差时
才将角度映射到周期范围。

最短角度差：

```cpp
float shortest_angle_delta(float from, float to)
{
    return atan2f(sinf(to - from), cosf(to - from));
}
```

## 9. 单根刚性指针的动力学

将每根指针近似为绕表盘中心转动的刚体：

```text
I_i × θ̈_i = Στ_i
```

对于长度 `L`、质量 `m` 的均匀细杆，绕端点的转动惯量近似为：

```text
I = (1/3) × m × L²
```

若指针的配重、装饰和质心不均匀，应直接将质量 `m`、质心距离 `l_c` 和转动惯量
`I` 从几何和材料积分派生；原型阶段若暂时手填，也必须作为一组经过一致性校验的参数，
而不是强行使用均匀细杆公式或允许三者互相矛盾。

### 9.1 移动、旋转表盘上的严格刚性指针方程

#### 世界惯性系中的原始约束模型

从物理概念上，应把世界惯性系 `W` 作为真值层。令：

- `x_O^W(t)`：表盘中心/铰点在世界中的位置；
- `R_WB(t)`：把表盘系向量转换到世界系的姿态矩阵；
- `R_BW = R_WBᵀ`；
- `n^W = R_WB e_z`：表盘法向；
- `s`：指针中心线上某质量元到铰点的有符号距离。

该质量元在世界中的位置是：

```text
x_i^W(s,t) =
    x_O^W(t)
  + R_WB(t) s u_i^B(θ_i)
```

它的速度是：

```text
ẋ_i^W =
    V_O^W
  + R_WB [
        Ω^B × (s u_i)
      + s θ̇_i t_i
    ]
```

这两式完整表达了用户所说的“指针原本具有自己的惯性运动，而铰点被表壳带着在三维
世界中移动”。世界系中不需要虚构“惯性力”；真实作用包括重力、铰点/表盘平面约束
反力，以及转轴、触摸、碰撞或主动回归产生的力矩。

指针方向满足：

```text
u_i^W = R_WB u_i^B(θ_i)
|u_i^W| = 1
u_i^W · n^W = 0
```

后两项分别是定长约束和“指针必须留在表盘平面内”的约束。若直接在世界系积分
`u_i^W`，每一步都必须用拉格朗日乘子或约束求解器同时满足这些条件，并求出移动铰点和
旋转平面对指针施加的反力。

更紧凑的做法是保留一个广义坐标 `θ_i`，通过
`u_i^W = R_WB u_i^B(θ_i)` 自动满足约束。这里使用表盘相对角只是**坐标参数化**，并不
代表把表盘当作物理上的惯性基准。

将世界系动能和重力势能写为：

```text
T_i = 0.5 ∫ |ẋ_i^W|² dm
V_i = -∫ (g^W)ᵀ x_i^W dm
```

代入拉格朗日方程：

```text
d/dt [∂(T_i - V_i)/∂θ̇_i]
-      ∂(T_i - V_i)/∂θ_i
= Q_other,i
```

`x_O^W` 和 `V_O^W` 会在化简中消去，只留下铰点加速度 `A_O^W`。这正是为什么程序不
需要先恢复表盘在房间里的绝对位置，就能得到正确的相对指针轨迹。

#### 若直接以世界方向向量作为状态

如果希望物理实验版完全在世界系积分，可保存 `u_i^W` 和 `u̇_i^W`。令：

```text
t_i^W = n^W × u_i^W

a_t,i =
    (H_i / I_i)
    × (t_i^W)ᵀ (g^W - A_O^W)
  + τ_other,i / I_i
```

由单位长度约束和表盘平面约束：

```text
u_i · u_i = 1
u_i · n = 0
```

可得完整方向向量加速度：

```text
ü_i =
    a_t,i t_i
  - |u̇_i|² u_i
  + a_n,i n

a_n,i =
    -u_iᵀ n̈
    -2 u̇_iᵀ ṅ
```

其中：

- `a_t t` 是允许自由度上的真实动力学；
- `-|u̇|²u` 保持单位长度；
- `a_n n` 让指针持续留在运动中的表盘平面。

这种写法最接近“世界中的独立指针＋移动圆心”的直觉，但实现并不更简单：数值误差会
破坏两个约束，必须使用拉格朗日乘子、RATTLE/投影约束或每步正交化，并验证约束过程
不凭空增减能量。正式固件使用 `R_WB + θ_i` 的最小坐标能自动满足相同约束。

#### “两个力与一个固定点”的准确版本

对最理想的无摩擦刚性指针，可以把系统理解为：

1. 作用于全部质量、可合成为质心力的世界重力；
2. 移动铰点和旋转表盘平面产生的约束反力；
3. 一个位置和姿态随时间变化的铰点约束，而不是世界中的固定点。

“惯性静止、匀速圆周或摆动”属于指针的初始状态和角动量，不是第三股力。在世界系里
也不存在独立的“惯性力”；只有改用随表壳运动的非惯性坐标后，约束的影响才可等效成
`g - A_O`、欧拉项和离心项。

产品模型还必须在需要时加入转轴阻尼、触摸、碰撞和时间回归力矩。所以“两股力＋一个
点”适合作为直觉草图，但不能作为完整的软件接口。更准确的软件抽象是：

```text
WorldKinematics      世界重力、表壳姿态、Ω、表心有效加速度
MovingPivotConstraint 移动铰点与旋转表盘平面
HandBody             质量分布、惯量、柔性和当前动量
TorqueProviders      转轴、触摸、碰撞、回归等可组合力矩
```

三根指针应各自封装 `HandBody` 状态和物性，但 `WorldKinematics` 与
`MovingPivotConstraint` 是同一时刻的共享只读输入。不要让三根指针各自积分一份表心
位置或姿态，否则传感器误差和时间步差异会让同一个铰点在软件中分裂成三个位置。

#### 任意三维运动没有单一“世界指针角”

若表盘法向固定、表壳只绕法向旋转，可以定义标量：

```text
φ_i = ψ_device + θ_i
```

并把 `φ_i` 理解为指针的世界绝对角度。任意三维翻滚时，表盘平面本身不断改变，世界中
不存在一个对所有姿态连续有效的单一标量角度。此时应保存：

- 表壳三维姿态 `R_WB`；
- 指针在表盘内的一自由度 `θ_i`；
- 或等价的受约束世界方向向量 `u_i^W`。

直接保存 `u_i^W` 仍要处理平面约束和几何相位；使用 `R_WB + θ_i` 是更小、更稳定的
表示。渲染时只需使用 `u_i^B(θ_i)`，调试世界姿态时再计算
`u_i^W = R_WB u_i^B`。

若研究阶段确实需要一个“尽量不随表壳自转”的世界平面基底，可对法向 `n(t)` 做
平行输运：

```text
ω_PT = n × ṅ
ṗ = ω_PT × p
q = n × p
u = cos β p + sin β q
```

其中 `(p,q)` 以最小旋转跟随表盘法向，`β` 是相对该基底的面内角。但法向沿三维闭合
路径运动后可能出现几何相位，所以 `β` 仍不能简单解释为一个全局固定的世界角。

必须明确，“指针保持世界方向”不能无条件推广成“任意三维下 `u_i^W` 永远不变”。
真实机械表针被轴承和表盘约束在当前表盘平面：

- 表壳只绕法向旋转时，指针可在平面内反向运动，近似保持世界朝向；
- 表壳发生俯仰/横滚时，表盘法向改变，平面约束必然对指针施力；
- 若强行冻结 `u_i^W` 后再投影到屏幕，可能出现长度缩短、方向翻转和能量不连续；
- 只有把产品设定改成“中心球铰上的自由三维指针”，才可以让其像小陀螺一样自由保持
  三维方向，但那已经不是普通机械表针模型。

本项目默认采用“移动铰点＋旋转平面约束”的机械表针模型。

#### 消去约束后的表盘系方程

令：

- `θ_i`：指针相对表壳的角度；
- `Ω^B = (Ω_x, Ω_y, Ω_z)`：表壳相对世界的三维角速度，在表盘系表达；
- `α^B`：表壳三维角加速度，在表盘系表达；
- `a_eff,O^B`：重力与中心平移合成后的有效加速度；
- `I_i`：指针绕表盘中心的转动惯量。

先把第 `i` 根指针视为质量集中在中心线上的细长刚体，定义：

```text
u_i = (sin θ_i, -cos θ_i, 0)
t_i = ∂u_i/∂θ_i = (cos θ_i, sin θ_i, 0)

H_i = ∫ s dm = m_i l_c,i
I_i = ∫ s² dm
```

其中 `H_i` 是相对转轴的有符号质量一阶矩，尾部配重可使其接近零或变号；`I_i` 是始终
为正的质量二阶矩。由拉格朗日方程可得任意三维表壳运动下的一自由度方程：

```text
I_i θ̈_i =
    H_i t_iᵀ a_eff,O^B
  - I_i α_z
  - I_i (Ω^B · u_i)(Ω^B · t_i)
  + τ_relative,i
```

三项基座作用分别是：

1. `H_i t_iᵀ a_eff,O^B`：真实重力和表心平移加速度的合成作用；
2. `-I_i α_z`：表壳绕屏幕法向角加速度产生的欧拉惯性力矩；
3. `-I_i(Ω·u_i)(Ω·t_i)`：任意三维转动产生的离心广义力矩。

`τ_relative,i` 包含：

- 转轴阻尼和摩擦；
- 触摸约束；
- 时间回归场；
- 柔性关节反力；
- 指针碰撞。

若表壳主要绕屏幕法向转动，即 `Ω_x ≈ Ω_y ≈ 0`，则：

```text
(Ω · u_i)(Ω · t_i) ≈ 0
```

这时退化为此前的二维基座激励复摆：

```text
I_i θ̈_i =
    [r_c,i × m_i a_eff,O^B]_z
  - I_i α_z
  + τ_relative,i
```

展开为适合第一版实现的二维标量形式：

```text
I_i θ̈_i =
    m_i l_c,i A_eff
      sin(φ_eff - θ_i)
  - I_i α_device,z
  - c_pivot,i θ̇_i
  - c_quad,i |θ̇_i|θ̇_i
  + τ_touch,i
  + τ_time,i
  + τ_flex,i
  + τ_collision,i
```

这是第一版刚性指针最适合实现的主方程；但代码和文档必须明确它的前提是忽略显著的
`Ω_x/Ω_y`。若实机动作录制显示三维翻滚很强，应启用上面的完整离心项。

对于具有有限宽度、但仍被约束在表盘平面内旋转的薄片指针，更一般的离心广义力矩为：

```text
τ_cf,i =
    0.5 × (Ω^B)ᵀ
    × [∂J_i^B(θ_i) / ∂θ_i]
    × Ω^B
```

其中 `J_i^B(θ_i)` 是指针相对表盘表达的三维质量惯量张量。细长指针满足
`J_parallel ≈ 0`、`J_tangent ≈ I_i`，上式才简化为
`-I_i(Ω·u_i)(Ω·t_i)`。这一区分可以避免把细杆近似误称为任意形状刚体的完全公式。

#### 推荐使用共轭角动量状态

对薄片/细杆指针，`θ_i` 的共轭动量为：

```text
p_i =
    ∂T_i / ∂θ̇_i
  = I_i (θ̇_i + Ω_z)
```

也可定义更直观的世界面内角速度状态：

```text
λ_i = p_i / I_i = θ̇_i + Ω_z
```

在二维法向旋转模型中：

- 惯性静止：`λ_i = 0`；
- 世界中匀速圆周运动：`λ_i = 常数 ≠ 0`；
- 摆动：`λ_i` 随重力和阻尼连续变化。

因此，用户所说的“原本静止、圆周运动或摆动”并不需要三套模型，只是同一个
`(θ_i, λ_i)` 状态具有不同初值和受力历史。

二维法向旋转时，它就是指针绕固定世界法向的绝对角动量；任意三维翻滚时，它是沿当前
表盘法向的广义动量分量，不能误称为完整的三维角动量向量。使用该状态后不必显式对
陀螺仪求导：

```text
ṗ_i =
    τ_eff,i
  + τ_cf,i
  + τ_relative,i

θ̇_i = p_i / I_i - Ω_z
```

二维模型中 `τ_cf,i = 0`；三维细杆模型中使用前述离心项。离散更新为：

```text
p_i ← p_i + (τ_eff,i + τ_cf,i + τ_relative,i) Δt
θ̇_i ← p_i / I_i - Ω_z
θ_i ← θ_i + θ̇_i Δt
```

这与显式加入 `-I_i α_z` 数学等价，但有三个工程优点：

- 不需要用噪声较大的相邻陀螺仪样本计算主方程中的 `α_z`；
- 无外部广义冲量时，表壳角速度突变仍能保持 `p_i` 连续；
- “表壳转动、指针保持世界方向”的行为直接由状态定义产生。

若需要进行 IMU 偏心修正，仍然要估计三维 `α`；此时 `α` 只用于把传感器测量点换算到
表心，不再重复加入角动量主方程。

#### “保持原地的惯性”的严格含义

在二维近似中，令表壳相对世界的屏内旋转角为 `ψ`。如果暂时忽略重力、中心平移、
阻尼、触摸和碰撞：

```text
I_i θ̈_i = -I_i ψ̈
```

所以：

```text
θ̈_i + ψ̈ = 0
```

也就是指针在世界系中的绝对角速度满足：

```text
d(θ̇_i + ψ̇)/dt = 0
```

如果指针一开始在世界系中静止，则表壳被旋转时，理想无摩擦指针会保持原来的世界朝向；
在屏幕上看，它会以相反方向转动。这正是“指针因为惯性保持原地”的物理定义。

该惯性不是人为给指针添加的动画延迟，而是由绝对角动量守恒和移动基座约束自然产生。

这里“保持原地”指保持世界坐标中的**绝对朝向或角动量**，不是质心保持空间位置不动。
指针根部被中心转轴约束，其质心必然跟随表盘中心平移。

#### 屏幕法向旋转的简化与任意三维旋转

在通用旋转参考系中确实存在离心力和科里奥利力。但对“绕同一个中心、只允许面内旋转”
的理想刚性细长指针：

- 当 `Ω_x = Ω_y = 0` 时，离心力沿指针半径方向，绕中心的力矩为零；
- 当 `Ω_x` 或 `Ω_y` 不为零时，离心力一般含有切向分量，其广义力矩为
  `-I_i(Ω·u_i)(Ω·t_i)`；
- 指针相对旋转产生的科里奥利项，在这个理想单自由度模型中的切向投影为零；
- 表壳角加速度产生的欧拉惯性项形成 `-I_i α_device,z`；
- 表盘中心平移通过 `a_eff,O^B` 产生质心扭矩。

所以第一版若明确限制为法向旋转，可以不计算离心和科里奥利角扭矩；若要覆盖任意三维
甩腕，则必须保留离心广义力矩。柔性多段指针中，这些项还会影响各段内力和形变，应由
多体系统的质量矩阵与速度耦合项统一处理。

#### 静态重力是主方程的特殊情况

设备中心没有平移加速度时：

```text
a_eff,O^B = g_screen
```

若质心轴与视觉指针轴重合，令：

```text
φ_gravity,i = φ_g
```

则退化为原来的重力扭矩：

```text
τ_gravity,i =
    m_i l_c,i G_parallel
    × sin(φ_gravity,i - θ_i)
```

若存在真实质心几何偏置，应直接通过 `r_c,i(θ_i)` 的向量式计算。只有启用艺术化独立
重力基准时，才使用：

```text
φ_gravity,stylized,i = φ_g + β_ref,i
```

并在配置和调试界面明确标记它不是公共真实重力方向。

### 9.2 时间重力场

为了让正确时间位置成为该指针自己的“最低势能点”，定义周期势能：

```text
U_time,i =
    K_time,i × (1 - cos(θ_i - θ_target,i))
```

对应回归扭矩：

```text
τ_time,i =
    -K_time,i × sin(θ_i - θ_target,i)
```

这一形式天然处理角度周期，比简单线性角度差更适合允许多圈旋转的指针。

需要注意：正弦势能在目标反方向 `180°` 处存在一个不稳定平衡点。理想数学状态下，
指针恰好停在该位置且速度为零时不会自行选择回归方向。工程上可以：

- 加入极小的确定性偏置；
- 根据进入该位置前的速度选择方向；
- 或使用限幅最短角弹簧，例如 `τ = τ_max × tanh(k × Δθ / τ_max)`。

不能依赖随机噪声替产品决定回归方向，否则相同操作可能产生不可预测的左右差异。

### 9.3 阻尼与摩擦

建议将阻力拆成：

```text
τ_damping =
    -c_linear × ω_relative
    -c_quadratic × |ω_relative| × ω_relative
    -τ_coulomb × sign(ω_relative)
```

其中：

```text
ω_relative = ω_hand - ω_reference
```

- 线性阻尼控制常规摆动衰减；
- 二次阻力限制高速甩动；
- 库仑摩擦模拟轴承低速摩擦；
- 接近零速度时需要平滑近似 `sign`，避免数值抖动。

`ω_reference` 必须根据阻尼来源选择：

- 重力模式中的转轴/轴承阻尼：参考手表外壳，通常取 `0`；
- 时间捕获阻尼：取该指针的连续时间目标角速度；
- 触摸约束阻尼：取手指估计角速度；
- 柔性内部阻尼：取相邻指针段的相对角速度。

若在重力模式中直接使用 `ω_hand - φ̇_g` 作为全部阻尼，会更像“跟踪重力方向的控制器”，
而不是安装在旋转外壳上的物理指针。该效果可以作为艺术化选项，但不能与真实轴承阻尼
混为一谈。

### 9.4 总扭矩

```text
Στ_i =
    w_eff × τ_eff,i
  + w_t × τ_time,i
  + w_touch × τ_touch,i
  + τ_cf,i
  - I_i × α_device,z
  + τ_flex,i
  + τ_collision,i
  + τ_damping,i
```

其中：

```text
τ_eff,i =
    [r_c,i × m_i a_eff,O^B]_z
```

权重 `w_eff`、`w_t` 和 `w_touch` 由全局模式与单针状态决定。`τ_eff` 已经同时包含
重力和中心平移惯性，不能再额外叠加同一次加速度对应的 `τ_gravity` 或
`τ_linear_accel`。`τ_cf` 只在启用任意三维基座模型时加入；二维法向旋转模型中为零。

若采用第 9.1 节的共轭角动量状态，则上式移除 `-I_i α_device,z`，其效果由
`θ̇_i = p_i/I_i - Ω_z` 自动产生。两种写法只能选择一种，不能同时使用。

## 10. 两种主要回归策略

### 10.1 自然摆动回归

自然摆动使用时间重力场和欠阻尼动力学。靠近目标时可线性化为：

```text
Iθ̈ + cθ̇ + Kθ = 0
```

自然频率：

```text
ω_n = sqrt(K / I)
```

临界阻尼：

```text
c_critical = 2 × sqrt(K × I)
```

阻尼比：

```text
ζ = c / c_critical
```

经验表现：

- `ζ = 0`：持续振荡；
- `0 < ζ < 1`：欠阻尼，有摆动；
- `ζ ≈ 0.25～0.40`：通常能看到两三次明显衰减摆动；
- `ζ = 1`：临界阻尼，最快无振荡回归；
- `ζ > 1`：过阻尼，回归稳但偏慢。

自然摆动模式建议使用分阶段参数：

1. `FREE_FLIGHT`：保留释放速度，时间吸附较弱；
2. `RETURN_SWING`：使用用户选择的阻尼比；
3. `CAPTURE`：接近目标后提高阻尼，快速清除尾部抖动；
4. `TIME_LOCKED`：角度和角速度跟随连续时间目标。

### 10.2 舒适曲线直接回归

舒适曲线模式不追求全过程物理守恒，而追求可预测、无眩晕和快速恢复可读时间。

推荐使用五次平滑曲线：

```text
h(u) = 10u³ - 15u⁴ + 6u⁵
u = clamp((t - t_start) / duration, 0, 1)
```

该曲线起点和终点的速度、加速度均为零。回归角度：

```text
θ(t) = θ_start + Δθ × h(u)
```

其中 `Δθ` 默认选择到预计结束时刻正确时间角度的最短路径：

```text
Δθ =
    shortest_delta(
        θ_start,
        θ_target(t_start + duration)
    )
```

结束后切换为持续跟随当前时间基准，避免在曲线结束瞬间产生跳变。

上述标准平滑曲线只适合回归开始时已经将速度平滑降到接近零的情况。指针仍在运动时
直接套用它，会在切换瞬间清除当前速度，产生明显顿挫。

正式实现应使用满足以下六个边界条件的五次多项式：

```text
θ(0) = θ₀          θ(T) = θ₁
θ̇(0) = ω₀         θ̇(T) = ω₁
θ̈(0) = α₀         θ̈(T) = α₁
```

令：

```text
θ(t) = a₀ + a₁t + a₂t² + a₃t³ + a₄t⁴ + a₅t⁵
```

则：

```text
a₀ = θ₀
a₁ = ω₀
a₂ = α₀ / 2

a₃ =
  [20(θ₁-θ₀) - (8ω₁+12ω₀)T - (3α₀-α₁)T²]
  / (2T³)

a₄ =
  [30(θ₀-θ₁) + (14ω₁+16ω₀)T + (3α₀-2α₁)T²]
  / (2T⁴)

a₅ =
  [12(θ₁-θ₀) - (6ω₁+6ω₀)T - (α₀-α₁)T²]
  / (2T⁵)
```

其中终点 `θ₁` 和 `ω₁` 应采用预计结束时刻的正确时间目标。这样曲线回归能够同时保证
位置、速度和加速度连续。

### 10.3 混合回归

混合模式建议作为默认：

1. 用户交互阶段完全按重力和材质运动；
2. 超时后先进行一至两次自然摆动；
3. 进入目标附近后切换到舒适曲线或高阻尼捕获；
4. 准确锁定当前时间。

混合模式能够保留物理感，同时保证时间快速可读。

### 10.4 用户可配置项

- 回归策略：自然摆动、舒适曲线、混合；
- 无操作等待时间；
- 回归时长；
- 允许摆动次数或阻尼比；
- 时间吸附强度；
- 末段捕获范围；
- 是否允许多圈回归；
- 三根指针是否同时归位；
- 三根指针是否使用相同完成时间；
- 回归过程中是否继续响应轻微 IMU；
- 触摸是否立即打断回归。

## 11. 无操作定时器

### 11.1 “无操作”不能等同于“IMU 没有数据”

IMU 始终有噪声，物理指针也可能在用户松手后继续自主摆动。如果任何传感器变化都重置
定时器，自动回归可能永远不会触发。

应记录：

```text
last_intentional_input_time
```

无操作计时必须使用系统单调时钟，而不是 RTC 墙上时间。NTP 校时、用户改时或时区
变化不应改变已经经过的无操作时长。

只有以下事件重置定时器：

- 实体按键有效短按；
- 触摸按下；
- 超过最小距离的触摸拖动；
- 触摸释放；
- 超过阈值且持续一定时间的明确甩动、翻转或转腕；
- 用户主动修改物理或材质设置。

“缓慢但持续地旋转手表”也属于明确操作，不能因为瞬时角速度较小而在用户操作中途触发
自动回归。动作检测建议同时包含：

- 快速路径：角速度或线性加速度超过阈值；
- 慢速路径：在一个时间窗口内累计姿态变化超过阈值；
- 两条路径都使用迟滞和最短持续时间，避免静态漂移续期。

以下事件不能重置：

- IMU 静态噪声；
- 指针自身摆动；
- 时间基准正常前进；
- 屏幕刷新；
- 很小的手部抖动；
- 自动回归产生的运动。

### 11.2 回归触发条件

建议同时满足：

```text
当前模式 == GRAVITY_PLAY
并且没有任何有效触摸
并且没有按键仍处于按下状态
并且当前时间 - last_intentional_input_time >= idle_timeout
```

可选地再加入：

- 明确动作结束后的安静窗口；
- 最大游玩时长，防止设备一直被轻微晃动而永久不归位；
- 低电量时缩短超时；
- 闹钟或通知出现时暂停自动回归。

### 11.3 推荐初始范围

以下仅作为可调试起点，不是最终产品参数：

- 无操作超时：`4～10 s`；
- 触摸释放过渡：`150～300 ms`；
- 舒适曲线回归：`450～900 ms`；
- 混合回归总时长：`1～2.5 s`；
- 最大重力交互时长：可选 `30～60 s`。

最终值应通过实机体验测试确定。

## 12. 触摸拨动、释放与连续性

### 12.1 命中测试

触摸指针时不能只检测末端点，应计算触点到指针线段或曲线的最短距离。多根指针重叠时
需要确定固定规则：

- 优先距离触点最近的指针；
- 距离相同时优先视觉最上层；
- 或连续点击在重叠指针间轮换。

### 12.2 释放速度估计

保存最近若干个带时间戳的触摸角度：

```text
(t0, θ0), (t1, θ1), ..., (tn, θn)
```

先对角度解包裹，再使用加权线性拟合或加权平均估计释放角速度。越新的样本权重越高。

不能只使用最后两个点，因为一次触摸采样抖动就可能产生异常高速旋转。

触摸坐标估计得到的是相对表盘角速度 `θ̇_finger`。若物理状态使用共轭动量，直接约束式
触摸在释放瞬间应转换为：

```text
λ_release = θ̇_finger + Ω_z
p_release = I × λ_release
```

否则在用户一边转腕一边松手时，会错误丢掉表壳自身的世界角速度分量。若触摸始终通过
有限力矩弹簧进入同一物理积分器，`p` 已连续演化，则不应在释放时再次覆盖它。

### 12.3 控制权平滑交接

触摸释放后：

- 保留指针当前角度；
- 保留估计得到的释放角速度；
- 保留柔性形变量和内部速度；
- 触摸权重降为零；
- IMU 权重在短时间内由零平滑恢复；
- 时间吸附根据当前模式决定何时恢复。

## 13. 材质系统

### 13.1 “材质惯性”的严格解释

“钢更重，所以一定比铝运动得更慢”对当前复摆模型并不总是成立。

假设两根指针：

- 几何形状完全相同；
- 都是均匀单一材料；
- 只有密度不同；
- 没有阻尼、柔性、空气阻力和碰撞。

那么密度增加会同时按相同比例增加：

- 质量 `m`；
- 重力/中心加速度产生的扭矩 `m l_c A_eff`；
- 转动惯量 `I`。

角加速度中的质量比例会抵消：

```text
θ̈ ∝ (m l_c / I) × A_eff
```

对于几何完全相同、密度均匀缩放的指针，`m l_c / I` 不变。因此只修改密度，不能让
钢针和铝针在理想刚性重力场中产生明显不同的角轨迹。

同样，在没有其他扭矩时：

```text
I θ̈ = -I α_device
```

两边的 `I` 也会抵消。所有理想自由指针都会保持自己的世界惯性姿态，而不是“更重的
指针保持得更用力”。

因此，“材质惯性保持原地”应严谨表述为：

> 每根指针依据自己的质量分布与转动惯量遵守角动量定律；材质差异主要通过质量分布、
> 柔性、内部损耗、碰撞和与材质配套的几何/轴承参数体现，而不是给材料名称直接乘一个
> 任意惯性延迟。

### 13.2 材质、几何、转轴和艺术参数必须分层

建议至少拆成七组：

```cpp
struct MaterialProfile {
    float density_kg_m3;
    float youngs_modulus_pa;
    float loss_factor;
    float allowable_strain;
};

struct GeometryProfile {
    float length_m;
    float width_m;
    float thickness_m;
    float tip_mass_kg;
    float counterweight_mass_kg;
    float counterweight_radius_m;
    // 正式版应保存沿长度变化的轮廓、截面和离散质量点
};

struct PivotProfile {
    float viscous_damping_nms_rad;
    float coulomb_friction_nm;
    float static_friction_nm;
};

struct AerodynamicProfile {
    float quadratic_drag_nm_s2_rad2;
};

struct ContactProfile {
    float restitution;
    float friction;
    float virtual_grip_torque_nm;
};

struct FlexibleProfile {
    float effective_ei_nm2;
    float modal_damping_ratio;
    float virtual_release_energy_j;
};

struct ArtisticMotionProfile {
    float inertia_exaggeration;
    float gravity_exaggeration;
    float damping_exaggeration;
    float visual_bend_gain;
};
```

其中：

- `MaterialProfile` 描述材料本体；
- `GeometryProfile` 描述指针形状和配重；
- `PivotProfile` 描述中心转轴，不属于指针材料；
- `AerodynamicProfile` 描述相对环境的高速阻力；
- `ContactProfile` 描述触摸或两物体接触；恢复系数和摩擦严格来说属于一对接触材料，
  不是单个材料的固有常数；
- `FlexibleProfile` 可由材料与几何推导，也可作为 MCU 简化模型参数；
- `ArtisticMotionProfile` 明确属于风格化效果，不能伪装成真实材料常数。

### 13.3 从材质和几何推导质量属性

令指针沿长度坐标为 `s`，截面积为 `A(s)`，材料密度为 `ρ(s)`：

```text
dm = ρ(s) A(s) ds
```

总质量：

```text
m = ∫ dm
```

质心距离：

```text
l_c = (1/m) ∫ s dm
```

绕中心转轴的转动惯量：

```text
I = ∫ s² dm
```

质量一阶矩：

```text
H = ∫ s dm = m l_c
```

若指针包含穿过转轴的尾部配重，`s` 应取有符号坐标：视觉指针方向为正、尾部为负。
此时 `H` 和有符号 `l_c = H/m` 可以接近零甚至为负，而转动惯量 `I = ∫s²dm` 始终为
正。强行把 `l_c` 存成无符号半径会丢失配重翻转平衡方向的信息。

更一般的二维轮廓应使用面积积分，并满足平行轴定理：

```text
I_O = I_C + m |r_c|²
```

正式实现应由几何轮廓、厚度、密度和配重自动派生 `m`、`r_c`、`H`、`I_O` 以及三维
惯量张量，禁止将这些量全部作为互不相关的手填参数。否则一个预设可能同时声称“质心
在轴上”却又拥有非零 `H`，在数学上自相矛盾。

若有末端配重 `m_tip`：

```text
m_total = m_body + m_tip
I_total = I_body + m_tip L²
```

控制指针对统一有效加速度响应快慢的核心比值是：

```text
χ = m l_c / I
```

均匀细杆：

```text
l_c = L/2
I = mL²/3
χ = 3/(2L)
```

末端集中质量：

```text
l_c = L
I = mL²
χ = 1/L
```

所以真正改变“甩动后惯性手感”的有效方法包括：

- 改变指针长度；
- 改变厚度或宽度沿长度的分布；
- 在根部或末端增加配重；
- 改变转轴阻尼；
- 允许材料发生不同程度的柔性变形；
- 在碰撞中使用不同质量和恢复系数。

若指针带有尾部配重，使质心接近中心：

```text
l_c ≈ 0
```

那么静态重力和表盘中心的统一平移加速度几乎不会产生转动扭矩，即使该指针的转动惯量
很大。产品要获得明显的摆锤效果，必须确保每根指针具有非零、可控的质心偏置。

### 13.4 刚性阻尼与材料内部阻尼的区别

理想刚体本身没有弯曲形变，因此不存在可见的“材料内部弯曲阻尼”。刚性指针绕中心
旋转时的耗散主要来自：

- 转轴黏性阻尼；
- 转轴静摩擦和库仑摩擦；
- 空气或虚拟介质阻力；
- 指针之间的碰撞耗散。

材料内部损耗只有在柔性模型中才直接起作用，例如指针弯曲后的余振衰减。

产品仍然可以提供“黄铜、玻璃、橡胶”等材质预设，但每个预设应是一组符合视觉预期的
“材质＋几何＋转轴＋声音”组合，而不是只修改一个名为 `material_damping` 的数。

### 13.5 材质与几何对柔性的影响

必须区分屏幕平面内弯曲和屏幕法向弯曲。设指针在屏幕平面内的宽度为 `b`，屏幕法向
厚度为 `h`：

```text
屏幕平面内弯曲：I_area,z = h × b³ / 12
屏幕法向弯曲：  I_area,y = b × h³ / 12
```

弯曲刚度：

```text
K_bend ∝ E × I_area
```

本项目显示的是屏幕平面内弯曲，应主要使用 `I_area,z`。其中：

- `E`：材料杨氏模量；
- `b`：指针宽度；
- `h`：指针厚度。

对屏内弯曲，宽度 `b` 以三次方影响刚度；对屏幕法向弯曲，厚度 `h` 以三次方影响刚度。
因此“材料相同”不代表柔性相同，“材料不同”也不代表只需要修改密度。

均匀悬臂梁第一弯曲模态的近似圆频率为：

```text
ω_1 ≈
    (1.875² / L²)
    × sqrt(E I_area / (ρ A))
```

相同几何下，其量级随 `sqrt(E/ρ)` 变化；材料损耗因子决定余振衰减，而不是刚体转轴
摩擦。毫米尺度真实金属指针的弯曲频率往往高于画面可清楚呈现的范围。如果产品需要
肉眼明显的“黄铜针弯曲”或“钢针回弹”，应明确使用：

- `E_real`：真实材料参数，用于物理参考；
- `E_effective`：为交互体验降低后的有效弹性模量；
- 或 `visual_bend_gain`：只放大绘制形变。

这类预设更适合命名为“黄铜感”“玻璃感”，避免宣称是现实材料的精确复刻。

### 13.6 动态参数与收敛速度

在某一时刻将有效加速度方向附近线性化，等效角刚度为：

```text
K_eff = m l_c A_eff
```

局部自然频率：

```text
ω_n = sqrt(K_eff / I)
    = sqrt(m l_c A_eff / I)
```

若转轴线性阻尼为 `c`，局部阻尼比：

```text
ζ = c / (2 sqrt(I K_eff))
```

这意味着强烈甩动时 `A_eff` 可能远大于 `g`，指针的瞬时自然频率也会升高。固定时间步
和最大有效加速度必须按最强预期动作设计，而不能只按静态 `1g` 调参。

### 13.7 材质配置的产品层表达

材质预设最终可以影响：

- 质量和转动惯量；
- 质量沿长度的分布；
- 启动、停止与碰撞响应；
- 转轴和柔性摆动衰减；
- 高速空气阻力；
- 指针弯曲幅度；
- 自动脱手阈值；
- 碰撞反弹；
- 回弹后的余振；
- 配套纹理和声音。

时间捕获阻尼应与材质阻尼分离。否则用户选择低阻尼材质后，指针可能长时间无法准确
归位。

为兼顾严谨性和可玩性，建议同时提供：

- `PHYSICAL`：严格由材质、几何和转轴参数推导；
- `STYLIZED`：允许使用受限的艺术夸张系数；
- 所有预设仍受角速度、能量、刚度和数值稳定范围限制。

### 13.8 单位与参数一致性

内部物理计算建议统一使用 SI 单位：

| 参数 | 单位 |
|---|---|
| 长度 | `m` |
| 时间 | `s` |
| 角度 | `rad` |
| 质量 | `kg` |
| 加速度 | `m/s²` |
| 质量转动惯量 `I` | `kg·m²` |
| 截面二次矩 `I_area` | `m⁴` |
| 力矩 | `N·m` |
| 弹性模量 | `Pa` |
| 转动刚度 | `N·m/rad` |
| 转动阻尼 | `N·m·s/rad` |

屏幕像素通过统一的 `meters_per_pixel` 转为虚拟长度。不能让质量属性使用米，而触摸
杠杆臂仍使用像素，否则不同分辨率或缩放下物理手感会改变。

派生参数应由材质和几何自动计算，避免同时允许用户手填互相矛盾的 `mass`、`l_c` 和
`I`。至少检查：

```text
m > 0
I > 0
I >= m |r_c|²
E > 0
I_area > 0
c >= 0
0 <= restitution <= 1
friction >= 0
```

## 14. 柔性指针与达到夹角后自动脱手

### 14.1 简化二段模型

第一版柔性实现可将指针看作：

```text
中心轴 ●────────○──────── 尖端
                 ↑
              柔性关节
```

状态包括：

```cpp
struct FlexibleHandState {
    float root_angle;
    float root_angular_velocity;
    float bend_angle;
    float bend_angular_velocity;
};
```

弯曲扭矩：

```text
τ_bend =
    -K_bend × φ
    -C_bend × φ̇
```

弹性势能：

```text
E_bend = 0.5 × K_bend × φ²
```

长度为 `l_seg` 的等效柔性关节，可从梁参数近似得到：

```text
K_bend ≈ E I_area / l_seg
C_bend = 2 ζ_bend sqrt(K_bend I_joint,eff)
```

其中 `I_joint,eff` 是该关节看到的等效质量转动惯量，`ζ_bend` 是目标模态阻尼比。
这样 `K_bend`、`C_bend` 与材质、几何和离散段长保持一致，而不是互不相关地凭感觉填写。

### 14.2 自动脱手

若相邻柔性段长度为 `l_seg`、内部夹角为 `φ`，小变形曲率近似为：

```text
κ ≈ φ / l_seg
```

本项目显示的是屏幕平面内弯曲，若指针屏内宽度为 `b`，最外侧纤维应变近似为：

```text
ε_max ≈ |κ| b / 2
```

因此由材料允许应变推导的屏内弯角上界约为：

```text
|φ_allow| ≈ 2 ε_allow l_seg / b
```

若模拟的是屏幕法向弯曲，才把上式的 `b` 换成法向厚度 `h`。这一点必须与第 13.5 节
选择的截面二次矩保持一致。

满足以下任一条件且仍在向外弯曲时，可以解除触摸约束：

```text
ε_max >= virtual_release_strain
或
E_bend >= release_energy
或
所需触摸约束力矩 > virtual_grip_torque
```

脱手时只解除触摸约束，不能清零弯曲角和弯曲速度。储存的弹性能量应自然转化为根部旋转
和指针余振。

真实材料达到屈服通常意味着永久变形甚至损伤，并不意味着会自动从手指下“松开”。
所以产品中的自动脱手应定义为**虚拟抓持/脱扣机构**：材料允许应变可作为安全参考，
真正触发阈值由抓持力矩、储能和体验参数共同决定。

为避免阈值附近反复捕获，需要：

- 释放迟滞；
- 最短不可重新捕获时间；
- 最大弹性势能限制；
- 最大角速度限制；
- 明确的视觉或声音反馈。

### 14.3 多段模型

后续可升级为三至五段弹簧链：

```text
●──○──○──○──○
```

每个关节拥有相对角、刚度和阻尼。绘制时可通过节点生成贝塞尔曲线或平滑折线。

段数越多、刚度越高，数值系统越“刚性”，需要更小固定时间步或使用
Verlet、Position Based Dynamics 等约束方法。

多段模型的严谨形式应写成：

```text
M(q) q̈
+ C(q, q̇) q̇
+ D q̇
+ ∇U_bend(q)
= Q_eff
+ Q_Euler
+ Q_centrifugal
+ Q_Coriolis
+ Q_touch
+ Q_contact
```

其中：

- `q = [θ_root, φ_1, φ_2, ...]ᵀ`；
- `M(q)` 是由各段质量分布产生的质量矩阵；
- `C(q,q̇)` 包含多体速度耦合，包括柔性系统中的科里奥利/离心效应；
- `D` 是转轴和材料损耗形成的阻尼；
- `U_bend` 是弯曲势能；
- `Q_eff` 由表盘中心有效加速度场作用于每段质心产生；
- `Q_Euler`、`Q_centrifugal`、`Q_Coriolis` 是旋转表壳参考系的基座项；
- `Q_touch` 和 `Q_contact` 分别是触摸与碰撞广义力。

对点质量段近似，令第 `j` 段质心为 `r_j(q)`，位置雅可比
`J_j = ∂r_j/∂q`，可写出：

```text
Q_eff =
    Σ_j m_j J_jᵀ a_eff,O^B

Q_Euler =
    -Σ_j m_j J_jᵀ (α × r_j)
    + 各段自身转动惯量对应的欧拉项

Q_centrifugal =
    -Σ_j m_j J_jᵀ [Ω × (Ω × r_j)]

Q_Coriolis =
    -Σ_j 2m_j J_jᵀ [Ω × (J_j q̇)]
```

有限长度刚体段还必须在质量矩阵和基座项中加入各段绕质心的转动惯量；最稳妥的方法是
从整套动能和势能统一推导，而不是分别给各关节添加经验扭矩。

这解释了为什么单根刚性指针的科里奥利广义力矩为零、二维法向旋转时离心力矩也为零，
而多段柔性模型通常不能删除这些项。任意三维基座运动下，即使单根刚性细杆也可能存在
第 9.1 节的离心广义力矩。

连续柔性梁的理论基础是 Euler–Bernoulli 梁方程：

```text
ρA × ∂²y/∂t²
+ c × ∂y/∂t
+ E I_area × ∂⁴y/∂x⁴
= f(x,t)
```

ESP32-S3 上不建议直接实时求解该偏微分方程；二至五段扭转弹簧链是更合适的离散近似。

还必须定义“柔性指针如何表示正确时间”：建议以指针根部中心轴方向作为读时方向。
进入 `TIME_LOCKED` 时，根部对准时间基准，同时柔性形变量平滑衰减到零。

## 15. 数值积分与实时循环

### 15.1 固定时间步

物理仿真必须使用固定时间步，不能直接把不稳定的屏幕帧间隔作为积分步长：

```text
IMU 采样 → 滤波/融合 → 固定步长物理 → 渲染插值 → AMOLED
```

推荐从以下范围开始实测：

- IMU：选择芯片实际支持的 `200～500 Hz` 附近档位；
- 刚性物理：固定 `200～240 Hz`；
- 柔性物理：`200～500 Hz`，必要时在一个刚性步内增加子步；
- 渲染：`30～60 FPS`。

IMU、物理和渲染可以使用不同频率，但必须通过样本时间戳插值或保持，不得假设三者
同帧。具体频率以设备性能、显示驱动、动作带宽和功耗测试为准。

### 15.2 半隐式欧拉

刚性指针第一版可以使用半隐式欧拉：

```text
ω(t + dt) = ω(t) + α(t) × dt
θ(t + dt) = θ(t) + ω(t + dt) × dt
```

它通常比先更新位置再更新速度的显式欧拉更适合弹簧和摆动系统。

### 15.3 稳定性保护

- 单帧累计时间设置上限；
- 恢复前台后丢弃过大的 `dt`；
- 角速度、角加速度和扭矩限幅；
- 对所有参数设置安全范围；
- 检查 `NaN` 和无穷值；
- 物理状态异常时回退到正确时间；
- 高刚度柔性材料使用更小时间步；
- 渲染丢帧时不能减少物理更新的总时间；
- 传感器失联时平滑衰减外力，而不是保留最后一个冲击值。

对于自然频率为 `ω_n` 的高刚度弹簧，可将以下条件作为显式积分的初步安全检查：

```text
ω_n × dt < 0.2～0.3
```

这不是严格适用于所有求解器的稳定性证明，但能及时暴露“刚度过高、时间步过大”的
危险组合。超出范围时应降低刚度、增加物理子步，或改用 XPBD 等约束求解方式。

开发阶段还应监控总模拟能量：

```text
E_total =
    转动动能
  + 时间势能
  + 弯曲势能
```

在没有触摸和有效 IMU 输入时，总能量不应持续增加。若能量不断上升，通常意味着传感器
噪声持续注能、阻尼符号错误、时间步不稳定或外力被重复计算。

为避免极端输入破坏数值稳定，可使用连续软限幅：

```text
a_used =
    a_max tanh(|a_eff| / a_max)
    × a_eff / |a_eff|
```

`|a_eff| = 0` 时直接取零。必须在文档和调试界面注明：软限幅属于产品安全/体验处理，
不是严格物理；达到传感器量程边界后，真实轨迹已经不可恢复。

### 15.4 刚性模型参考更新流程

以下流程对应“世界系推导、表盘系约化计算”的推荐实现：

```text
每个带时间戳的 IMU 样本：
    f_S^B ← 校准并完成 M→B 坐标变换的加速度计比力
    Ω^B   ← 校准、换成 rad/s 的陀螺仪角速度

    若启用 IMU 偏心修正：
        α^B ← 带限微分器/观测器(Ω^B)
        a_eff,O^B ←
            -f_S^B
            + α^B × r_OS^B
            + Ω^B × (Ω^B × r_OS^B)
    否则：
        a_eff,O^B ← -f_S^B

    记录饱和、时间戳异常和可信度

每个固定物理步、每根指针 i：
    u_i ← (sin θ_i, -cos θ_i, 0)
    t_i ← (cos θ_i,  sin θ_i, 0)

    τ_eff ← H_i × dot(t_i, a_eff,O^B)

    若启用三维基座细杆模型：
        τ_cf ← -I_i dot(Ω^B, u_i) dot(Ω^B, t_i)
    否则：
        τ_cf ← 0

    τ_other ←
        τ_pivot
      + τ_touch
      + τ_time
      + τ_collision

    p_i ← p_i + (τ_eff + τ_cf + τ_other) Δt
    θ̇_i ← p_i / I_i - Ω_z
    θ_i ← θ_i + θ̇_i Δt

渲染：
    对物理状态做插值
    用 θ_i 绘制表盘内方向
    调试时可计算 u_i^W = R_WB u_i^B
```

关键约束：

- `a_eff,O^B` 是三根指针共享的同一份基座输入；
- `H_i`、`I_i`、阻尼、柔性和状态由每根指针独立保存；
- 使用共轭动量后，不再把 `-I_i α_z` 额外加入 `τ_other`；
- 传感器饱和时只能限制本步输入功或进入退化，不能猜测被截掉的峰值；
- 从直接走时切入物理模式时，先设置
  `p_i = I_i(θ̇_time,i + Ω_z)`，避免解锁瞬间凭空改变世界角速度；
- 舒适曲线模式若暂时直接规定 `θ/θ̇`，退出时必须设置
  `p_i = I_i(θ̇_i + Ω_z)`，保证重新进入物理模式时连续。

其中 `relative_angular_velocity` 可由共轭动量和当前 `Ω_z` 派生；保留字段仅用于缓存和
调试，不能让两个状态源各自独立更新。传感器饱和或时间戳异常时，
`KinematicSample::trustworthy` 必须变为 `false`，物理层只能平滑限制能量或退化，不能
假装恢复出真实峰值。`KinematicSample` 刻意不保存六轴 IMU 双积分得到的绝对位置；
`body_to_local_world` 的世界原点和航向允许是任意规范，只用于姿态、约束解释和调试。

## 17. 按键实现注意事项

ESP32-S3-Touch-AMOLED-1.8 的实体按键还承担上电、关机或下载相关功能。实现前需要确认
具体硬件版本和按键行为。

建议：

- 使用有效短按切换 `TIME_DISPLAY → GRAVITY_PLAY`；
- 在按键释放事件确认短按后再执行，可减少误触；
- 做硬件或软件消抖；
- 不覆盖长按关机等必要系统行为；
- 运行状态下避免让 BOOT 键行为影响固件下载恢复；
- 屏幕上同步提供模式变化反馈；
- 若按键按住期间也需要物理效果，应把“按住效果”和“模式切换事件”分开。

按下侧键本身会给设备带来一次机械冲击。若模式切换后立即把这次冲击作为 IMU 外力，
指针可能每次都向固定方向异常弹出。建议在按键边沿前后设置很短的冲击抑制窗口，或对
该窗口内的线性冲量和角加速度单独限幅。抑制窗口只过滤机械按键尖峰，不能造成明显的
正常动作延迟。

## 18. 时间正确性和系统生命周期

### 18.1 回归终点持续前进

自动回归期间 RTC 仍然走时。舒适曲线应瞄准预计结束时刻的时间角度；自然摆动则每个
物理步重新计算动态目标。

### 18.2 NTP 校时和系统时间跳变

时间修正需要分类：

- 小幅校正：平滑改变时间基准；
- 大幅校正：显示提示后使用舒适曲线回归；
- 时区或夏令时变化：作为明确模式事件处理；
- 用户正在触摸：延迟视觉回归，但后台保存最新时间；
- 闹钟判断：使用 RTC/系统时间，不能依赖物理指针当前角度。

### 18.3 休眠和唤醒

- 进入休眠前保存配置，不必保存每一帧物理状态；
- 唤醒时默认直接显示正确时间；
- 若产品希望保留“连续物理世界”，可按休眠时长决定是否恢复；
- 过大的离线时间不能一次性积分；
- 低电量时可以禁用复杂柔性仿真和高刷新率。

## 19. 调试可视化

开发阶段建议提供隐藏的“物理实验室”页面，实时显示：

- 加速度计原始值；
- 陀螺仪原始值；
- 校准后的比力 `f_S^B`、零偏和轴映射；
- IMU 偏心修正的切向项、向心项和最终 `a_eff,O^B`；
- 融合姿态；
- 屏幕内重力方向和强度；
- 设备三维角速度、角加速度和滤波延迟；
- 加速度计/陀螺仪饱和标志、样本时间戳和可信度；
- 每根指针当前角度、目标角度、相对角速度和共轭角动量；
- 每根指针的有效场、欧拉、离心、时间、触摸、阻尼和碰撞等各项扭矩；
- 全局模式和每根指针状态；
- 无操作定时器剩余时间；
- 当前固定时间步和渲染帧率；
- 数值限幅、能量限制和异常恢复计数；
- 总机械能、传感器输入功和控制器输入功。

没有这些观测数据时，传感器噪声、坐标方向错误和物理参数问题很容易被误判成同一种
“手感不对”。

## 20. 验收测试

### 20.1 基准与姿态

- 完成六面静态加速度校准，三轴方向、符号和 `1g` 比例与定义一致；
- 分别绕三个正轴旋转，陀螺仪符号和 `C_BM` 映射与右手系一致；
- 设备竖直正放时，重力基准稳定指向六点；
- 设备缓慢旋转 `90°` 时，重力方向连续旋转，不发生跳变；
- 三根指针已在重力方向静止后，缓慢旋转设备，指针通过动力学追随移动基准而非瞬移；
- 使用至少三档旋转速度测试时，指针呈现合理且可重复的滞后差异；
- 停止旋转后，三根指针按各自材质围绕新重力方向摆动并收敛；
- 旋转跨过 `0°/360°` 时，重力方向、指针速度和阻尼保持连续；
- 持续缓慢旋转被识别为用户操作，不会在旋转途中自动回归时间；
- 屏幕平放时，指针不因重力投影噪声随机乱转；
- 三根指针可分别配置质心几何偏置、艺术基准偏置和材质预设；
- IMU 静止时不会产生持续虚假加速。

### 20.2 基座激励与数学一致性

- 静止数据中 `a_eff,O^B = -f_O^B`，程序没有再次叠加第二份 `1g`；
- 表心沿当前指针径向作合成加速时，`τ_eff` 近似为零；
- 表心沿当前指针切向作合成加速时，`|τ_eff|` 接近最大值，方向与叉乘结果一致；
- 匀速平移不产生额外惯性，平移加速方向反转时指针初始角加速度同步反转；
- 自由落体合成数据回放中 `a_eff` 趋近零，仅保留其他真实扭矩；
- 纯绕表心、屏幕法向匀速旋转时，不出现伪造的离心或科里奥利角扭矩；
- 表壳法向角速度发生已知变化时，指针角动量连续，并满足
  `Δθ̇ ≈ -ΔΩ_z`；
- 给定三维 `Ω` 时，细杆离心力矩与
  `-I(Ω·u)(Ω·t)` 的解析值和符号一致；
- 使用转台/合成数据做偏心旋转时，中心修正前后的误差明显下降；
- 直接 `-Iα_z` 积分与共轭角动量积分在同一平滑输入下结果一致；
- 离线世界方向约束模型与 `(R_WB, θ, p)` 最小坐标模型在同一输入下轨迹一致；
- 任意三维翻滚时始终满足 `|u^W| ≈ 1`、`u^W · n^W ≈ 0`；
- 短时冲量回放满足第 7.11 节的 `Δω` 解析近似；
- 已逐样本积分的甩动不会被事件检测器再次施加一遍冲量；
- 加速度或陀螺仪削顶时设置不可信标志，并限制能量，不外推虚构峰值；
- 同一录制数据在 `30/60 FPS` 渲染和不同但足够小的物理步长下得到近似相同轨迹。

### 20.3 输入优先级

- 触摸某根指针时，该指针不与 IMU 抢控制权；
- 未触摸指针继续响应 IMU；
- 触摸可打断自动回归；
- 自动回归不会强制抢走正在触摸的指针；
- 多根指针重叠时命中结果可预测。
- 物理指针的触摸命中只在表盘页面启用，设置页滑动不会误拨指针。

### 20.4 回归

- 达到无操作超时后才触发回归；
- 传感器静态噪声不会无限延迟回归；
- 自然摆动模式按配置产生合理摆动次数；
- 舒适曲线模式无明显速度突变；
- 混合模式能保留物理感并快速恢复可读时间；
- 回归结束后显示的是结束时刻的正确时间，而不是开始回归时的旧时间。

### 20.5 材质与柔性

- 不同材质产生可辨认但稳定的轨迹差异；
- 相同几何只改变均匀密度时，理想刚性重力/平移自由轨迹应近似重合；
- 在相同有限触摸力矩下，提高转动惯量应降低角加速度；
- 改变末端配重或质心位置时，`H/I` 和甩动轨迹按推导发生变化；
- 质心配平到中心附近时，重力和中心平移扭矩应接近零；
- 达到材质夹角或能量阈值时可自动脱手；
- 脱手后弹性能量连续释放；
- 极端参数不会产生 `NaN`、穿越或无限加速；
- 所有材质最终都能通过独立捕获控制准确归位。

### 20.6 生命周期

- 息屏和唤醒后时间正确；
- NTP 大幅校时不会导致指针高速不可控旋转；
- 低帧率和瞬时卡顿不会改变仿真结果；
- IMU 暂时失联时系统平稳退化；
- 长按关机和固件下载恢复能力不受交互逻辑破坏。

## 21. 推荐开发顺序

1. 测量 IMU 相对表心的位置，校准轴映射、零偏、比例和屏幕旋转方向；
2. 录制静止、缓慢旋转、平移甩动、三维翻滚和饱和边界的原始带时间戳数据；
3. 绘制三根连续走时的普通指针；
4. 实现 `f_S^B → a_eff,O^B` 动力学路径，并用合成数据验证符号和重力不重复；
5. 实现单根刚性指针的固定时间步与共轭角动量积分；
6. 先验证二维法向旋转，再按实测动作决定是否启用三维离心项；
7. 加入实体键和 `TIME_DISPLAY/GRAVITY_PLAY` 切换；
8. 实现三根指针独立的几何、派生质量属性和状态；
9. 实现触摸命中、有限力矩捕获、拖动和释放速度估计；
10. 实现无操作定时器；
11. 实现自然摆动、舒适曲线和混合回归；
12. 加入分层材质预设，并完成密度抵消等回归测试；
13. 加入二段柔性、储能和虚拟自动脱手；
14. 加入调试可视化和自动化传感器回放测试；
15. 最后再增加指针碰撞、声音、纹理和更复杂的柔性模型。

## 22. 当前需要产品侧确认的决策

1. 模式切换是在实体键按下时立即发生，还是确认短按并松开后发生；
2. 再次短按是否立即回归时间，还是只允许定时器触发；
3. 设备持续被轻微移动时，无操作定时器是否继续计时；
4. 默认回归模式选择自然摆动、舒适曲线还是混合；
5. 重力模式下三根指针默认共享实际重力方向，还是带有艺术化独立偏置；
6. 触摸捕获一根指针时，其他指针是否仍响应 IMU；
7. 回归过程中触摸是否总能立即打断；
8. 指针允许旋转多少圈，是否需要速度上限；
9. 柔性自动脱手是首发核心功能，还是第二阶段功能；
10. 材质配置面向普通用户提供预设，还是同时开放高级参数；
11. 平放时冻结最后重力方向，还是切换到默认六点方向；
12. 时间大幅校正时直接回归，还是播放专门过渡动画；
13. 产品隐喻采用“被约束在表盘平面的机械表针”，还是“球铰自由三维指针再投影到屏幕”；
14. 首版只实现法向旋转简化，还是直接启用任意三维离心广义力矩。

## 23. 建议默认行为

在上述决策尚未全部确定前，推荐使用以下默认方案：

- 实体键短按并松开后进入重力交互；
- 采用“世界系推导＋表盘最小坐标计算”的移动铰点、旋转平面机械表针模型；
- 不对六轴 IMU 做绝对位置双积分，正式效果启用任意三维离心广义力矩；
- 重力模式默认使用真实公共重力方向，三根指针独立物性、默认零偏置；
- 被触摸指针由有限力矩触摸约束取得最高优先级，其他指针继续响应 IMU；
- 无操作 `6 s` 后触发混合回归；
- 混合回归先自然摆动，再在目标附近快速曲线捕获；
- 任何触摸立即打断自动回归；
- 平放时衰减姿态链的静态重力并冻结最后可靠方向，但保留真实平移甩动；
- 材质先提供安全预设，高级参数放入实验室页面；
- 柔性指针先使用二段模型；
- 所有异常都回退为准确、可读的普通时间表盘。

## 24. 最终数学模型摘要

当前项目推荐采用“世界系物理含义＋表盘系最小坐标”的混合模型。

### 24.1 共享基座输入

```text
a_eff,O^B =
    -f_S^B
  + α^B × r_OS^B
  + Ω^B × (Ω^B × r_OS^B)
```

若 IMU 可近似位于表心：

```text
a_eff,O^B ≈ -f_S^B
```

它已经等于 `R_BW(g^W - A_O^W)`，不能再添加第二份重力。

### 24.2 每根刚性细杆指针

```text
u_i = (sin θ_i, -cos θ_i, 0)
t_i = (cos θ_i,  sin θ_i, 0)
H_i = ∫s dm
I_i = ∫s²dm
```

推荐状态方程：

```text
ṗ_i =
    H_i t_iᵀ a_eff,O^B
  - I_i (Ω^B · u_i)(Ω^B · t_i)
  + τ_other,i

θ̇_i = p_i / I_i - Ω_z
```

其中：

- `p_i = I_i(θ̇_i + Ω_z)`；
- 第二项是任意三维表壳转动下的细杆离心广义力矩；
- 二维法向旋转时第二项严格为零；
- `τ_other` 包含转轴、触摸、碰撞和回归，不能再重复加入 `-Iα_z`。

有限宽度指针用：

```text
τ_cf =
    0.5 Ωᵀ [∂J^B(θ)/∂θ] Ω
```

代替细杆离心式。

### 24.3 物理与产品边界

- 世界位置 `x_O` 不需要由六轴 IMU 双积分；
- 指针是移动铰点和旋转表盘平面约束下的一自由度物体，不是自由三维陀螺；
- 相同几何只改均匀密度时，理想刚性重力/基座响应不变；
- 材质差异来自质量分布、转轴、`E I_area`、损耗、接触和有限触摸力矩；
- 触摸释放若直接设置状态，使用
  `p_release = I(θ̇_finger + Ω_z)`；
- 舒适曲线是主动控制，不要求守恒，但退出时必须把 `p` 与最终 `θ̇` 重新同步；
- 柔性阶段升级为质量矩阵多体模型，不给各段手工添加经验“惯性动画”。

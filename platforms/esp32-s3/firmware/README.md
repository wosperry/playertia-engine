# Playertia ESP32-S3 V2 Physical Clock Firmware

这是 Playertia 在微雪 ESP32-S3-Touch-AMOLED-1.8 V2 上的首个实机应用固件。
第一个应用固定为物理机械时钟，第二个应用保留为 Playground 占位页。

功能：

- 使用微雪官方 managed BSP v2.0.3 初始化 CO5300、CST820 和 LVGL；
- 使用 PCF85063A RTC 保存 UTC，表盘按 UTC+8 显示日期和时间；
- 使用 QMI8658 的 ±16g、±2048dps、250 Hz 数据驱动三指针物理模型；
- 使用六轴 Mahony 姿态估计计算表盘坐标系中的重力向量；
- 以 100 Hz 推进 Playertia Engine，以约 60 FPS 更新矢量表盘，按键以 200 Hz 扫描；
- 每 10 秒输出一次运行任务忙碌率、更新/渲染耗时、最大周期和截止时间错失数；
- 时针、分针、秒针均为完整刚性指针，并拥有独立 TIME_REF；
- 三针使用独立质量分布和高/中/低三级阻尼：时针沉稳、分针均衡、秒针轻快；
  自由旋转速度的标称半衰期约为 `0.4 s / 0.7 s / 1.35 s`。粘性阻尼
  控制常规衰减，二次阻尼压制高速疯转，非零库仑摩擦确保低速阶段最终停止；
- 锁定状态只跟随正确时间，完全隔离重力、表壳惯性和触摸；
- 自由状态完全隔离 TIME_REF，只接受重力、表壳惯性、材质阻尼和触摸；
- 触摸只在自由状态抓取最近指针，其约束优先于 IMU 输入；
- 再次短按后以约 280 ms 的舒适曲线回归当前正确时间，回归期间不受物理输入干扰，
  到时立即进入锁定状态；
- 正面右上角 BOOT/GPIO0 短按解锁/提前回归指针，长按约 900 ms 切换应用；
- 切换时执行旧应用 `unload`、新应用 `load`，再重建当前 LVGL 界面；
- 通过 USB Serial/JTAG 输出启动和切换日志；
- 表盘完全由 LVGL 样式、圆、线段和文字组成，不依赖大面积图片资源。

## 构建

使用项目锁定的 Espressif 官方工具链：

```bash
docker run --rm \
  -v "$PWD":/project \
  -w /project/platforms/esp32-s3/firmware \
  espressif/idf:v5.5.5 \
  idf.py build
```

首次构建会由 ESP Component Registry 下载锁定的微雪 BSP 及其依赖。

## 刷写

确认原厂备份存在且 SHA-256 正确后：

```bash
docker run --rm \
  --device=/dev/ttyACM0:/dev/ttyACM0 \
  -v "$PWD":/project \
  -w /project/platforms/esp32-s3/firmware \
  espressif/idf:v5.5.5 \
  idf.py -p /dev/ttyACM0 flash monitor
```

退出 monitor：`Ctrl+]`。

## 按键说明

BOOT/GPIO0 在固件运行期间区分短按和长按：

- 短按并松开：锁定时释放三针进入持续自由状态；自由时触发曲线回归；回归途中短按可重新释放；
- 长按约 900 ms：应用壳层切换到下一个应用，松开时不会再产生短按；
- 复位或上电时持续按住：仍会进入 ESP32-S3 下载模式。

右下角 PWR 属于 AXP2101 电源按键，本固件不改变其语义。

## 时间校准

PCF85063A 保存 UTC，界面当前固定按 UTC+8 显示。首次刷写时，如果 RTC 无效或明显
落后于本次构建时间，固件会用 UTC 构建时间作首次近似校准；已完成实机精确校准的 RTC
会被保留，后续普通重启不会把时钟重置回旧的构建时间。运行期间每 60 秒从 RTC
重新锚定一次单调时钟。

## 首次实机结果

2026-07-29 在 V2 实物上完成物理时钟首次构建、刷写和启动验证：

- ESP-IDF v5.5.5、Waveshare BSP v2.0.3；
- 应用镜像大小 `0x9ffa0`（约 640 KiB），8 MiB 应用分区剩余 92%；
- bootloader、分区表和应用镜像写入后均通过哈希校验；
- 启动确认 16 MB Flash、8 MB Octal PSRAM，PSRAM 内存测试通过；
- CO5300 初始化成功；
- CST820 由兼容驱动以 `CST816S 0x15` 名称探测成功；
- PCF85063A 初始化并完成当前时间校准；
- QMI8658 在 `0x6B` 初始化成功，使用 16g / 2048dps / 250Hz；
- `playertia.clock` 作为第一个应用正常加载；
- Playertia 生产物理核心已作为 ESP-IDF component 链入固件；
- 移除高开销大面积软件阴影后，连续观察未出现 watchdog、panic 或物理步拒绝；
- 避免逐帧重排 LVGL 图层并跳过未变化的指针/文字后，锁定表盘实测约
  `59.5～60.6 FPS`，运行任务忙碌率约 `62～83.5%`，物理更新平均
  `0.54～0.66 ms`，渲染调用平均 `8.0～12.1 ms`；
- 三针材料配置的最坏条件无量纲子步实测为 `0.2383`，低于引擎
  `0.2500` 的配置门限；配置异常时固件会自动回退到安全刚针参数，
  不再因应用加载失败进入重启循环；
- 应用壳层的短按派发与长按切换通过桌面单元测试。

仍需由实物操作完成视觉手感验收：IMU 到表盘坐标的正负轴方向、触摸四角坐标、实际
甩动强度和三针材料阻尼。RTC、SD、音频和 PMU 的其他专项能力不属于
本次时钟应用验收。

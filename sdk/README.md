# Playertia SDK Boundary

`sdk/` 是供外部应用接入的稳定边界，不暴露生产引擎内部对象布局。

```text
sdk/
├── c/                 # 版本化 C ABI；所有平台绑定的共同入口
├── packages/          # 各系统的原生安装包与语言封装
└── bindings/          # 按实际需求增加的上层框架绑定
```

当前可构建的是 `c/`。它提供不透明引擎句柄、明确宽度的数据类型、ABI 版本检查以及
输入/快照转换。平台包只能依赖该边界，不得直接复制物理方程。

C++ 接口仍用于引擎内部开发和验证；移动系统与第三方语言绑定优先使用 C ABI，避免
C++ 编译器、标准库和对象布局差异传播到接入方。
